🔔 Notification Watcher
A bookmarklet you can run on any other tab — YouTube, wherever — while global chat stays open in the background. It connects straight to the same chat database and pops a small, unobtrusive toast in the corner of the page whenever someone else sends a message. It never uses the browser's native notification permission, so it works even where those are blocked.
  1. Click Copy Bookmarklet below.
  2. Create a new bookmark in your browser (any name is fine, e.g. GC Notify).
  3. Paste the copied code as that bookmark's URL/address, then save it.
  4. On any other page, click the bookmark to start watching for new messages.
